# RF Design and Analysis Projects
Two RF design and analysis projects, containing transmission line matching, MATLAB-based filter optimization, 180° hybrid ring coupler analysis, waveguide and cavity resonator analysis and MATLAB-Based radiation pattern of antenna array visualization. 

## Project Overview
This repository contains an extensive analysis and computational design of high-frequency microwave circuits, through two different projects. Both projects are part of university work
In the first project, I experiment with analising transmission lines, matching networks and optimising microstrip LP filters through Smith Chart calculations and algorithmic methods. 
In the second project, make an extensive analysis on waveguides cavity resonators and antenna arrays, where I also use Matlab to plot each radiation pattern (both in 2D and 3D plots).
[Click here to read the Full Technical Analysis](RF_Analysis.pdf)

## Tools I used
* **Languages:** MATLAB, Python
* **Algorithms:** Non-linear optimization (`fmincon`), Gradient-based solvers
* **Simulation:** Online Smith Chart, Falstad Circuit Simulator

## Repository Structure
* `/scripts/` - MATLAB and Python source code for $$S_{11}$$ plotting and `fmincon` filter optimization.
* `/docs/` - Full technical report detailing theoretical derivations, Smith Chart movements, and mathematical proofs.
* `/assets/` - High-resolution plots of filter responses and optimization iterations.
