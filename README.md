# RF Design and Analysis Projects
Two RF design and analysis projects, containing transmission line matching, MATLAB-based filter optimization, 180° hybrid ring coupler analysis, waveguide and cavity resonator analysis and MATLAB-Based radiation pattern of antenna array visualization. 

## Project Overview
This repository contains an extensive analysis and computational design of high-frequency microwave circuits, through two different projects. Both projects are part of university work

In the [first project](RF_Analysis1.pdf), I experiment with analising transmission lines, matching networks and optimising microstrip LP filters through Smith Chart calculations and algorithmic methods. 

In the [second project](RF_Analysis2_Greek.pdf), make an extensive analysis on waveguides cavity resonators and antenna arrays, where I also use Matlab to plot each radiation pattern (both in 2D and 3D plots). 

Although the first project has been translated to English, the second project is only available in Greek.

## Tools used
* **Languages:** MATLAB, Python
* **Algorithms:** Non-linear optimization (`fmincon`), Gradient-based solvers
* **Simulation:** Online Smith Chart, Falstad Circuit Simulator

## Repository Structure
* `/code/` - MATLAB and Python source code for $$S_{11}$$ plotting and `fmincon` filter optimization.
